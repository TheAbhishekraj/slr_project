# Supervisor & Reviewer Sharing Bundle

This directory contains the final consolidated exports of the Systematic Literature Review, packaged for easy sharing.

## 1. Manuscript Versions

We have provided two versions of the manuscript PDF so you can choose which one to share depending on the target venue and reviewer preferences:

- **`manuscript_ieee_Standard_OptionA.pdf` (Recommended, 10 Pages):**
  - Contains the 5 narrative citations in the main bibliography.
  - References the remaining corpus via Appendix A.
  - Safest for strict page limits and readability.

- **`manuscript_ieee_FULL_REFS_OptionB.pdf` (16 Pages):**
  - Includes the full 287-study bibliography at the end of the PDF.
  - Useful if submitting to IEEE Access or if a reviewer specifically demands all citations inline.

## 2. Supplementary Data

- **`APPENDIX_A_All_287_Studies.md`**: A clean markdown table of all included studies. Essential supplementary material if submitting Option A.

## 3. Presentation Materials

- **`supervisor_summary.md`**: 2-page executive summary.
- **`slide_deck.md`**: 20-slide presentation deck.
- **`questions_and_answers.md`**: Anticipated Q&A prep.
- **`evidence_index.md`**: Audit trail of file hashes.

*(Note: Markdown files can be natively viewed on GitHub or exported to PDF using tools like Marp or Pandoc).*
